# Cung Đình Ký — bản chơi thử trên web

Bản đồ Hoàng thành (isometric, phong cách tranh Đông Hồ × Hàng Trống) với 4 mùa, ngày đêm,
lễ chầu buổi sáng, lính tuần, cung nữ, quan lại.

Bản 3D (xoay 360°, zoom, bấm công trình/người): `3d.html`. Cài như app: mở `3d.html` rồi chọn "Cài đặt" / "Thêm vào màn hình chính" trên trình duyệt.

Kho asset và tiến độ (ảnh từng công trình, nhân vật, việc đang làm): `kho/`.

Trang này được sinh tự động từ repo phát triển (riêng tư) bằng `tools/publish_web.py`. Không sửa tay.
